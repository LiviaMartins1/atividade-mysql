# atividade-mysql
Lição do professor Átila

======== Contextualização ========

-- Problema -- 

A Academia Vida Ativa oferece modalidades como musculação, funcional, dança e treinamento personalizado. Porém, enfrenta dificuldades para organizar os dados de alunos, planos, professores, aulas e pagamentos.
Como essas informações são registradas manualmente ou em planilhas separadas, podem ocorrer erros, dados duplicados e perda de informações. Também é difícil consultar alunos, controlar pagamentos, saber quais professores dão cada aula e quais modalidades têm mais alunos.

--- Solução ---

Para solucionar esses problemas, Lívía e Stacy desenvolveu um Banco de Dados Relacional no MYSQL.

O sistema irá organizar e centralizar as informações da academia, permitindo:

* Cadastrar alunos, professores, planos e modalidades;
* Registrar matrículas, aulas e pagamentos;
* Consultar informações dos alunos e professores;
* Verificar pagamentos e modalidades;
* Gerar relatórios por meio de consultas SQL.
