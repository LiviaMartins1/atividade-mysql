#  Sistema de Gestão de Academia — Vida Ativa


## Sobre o Projeto

A *Academia Vida Ativa* oferece diversas modalidades esportivas — como musculação, funcional, dança e treinamento personalizado. No entanto, a gestão das operações era realizada por meio de registros manuais e planilhas desconectadas, resultando em:

* Inconsistência e duplicação de dados;
* Perda de informações importantes;
* Dificuldade no controle de pagamentos e inadimplência;
* Falta de visibilidade sobre turmas, professores e modalidades mais procuradas.

Para resolver esses desafios, Lívia e Stacy desenvolveram uma solução centralizada baseada em Banco de Dados Relacional MySQL, otimizando a organização dos dados e viabilizando tomadas de decisão baseadas em relatórios precisos.


##  Objetivos e Funcionalidades

O banco de dados foi modelado para suportar todas as rotinas operacionais e gerenciais da academia:

*  *Gestão de Alunos e Professores:* Cadastro completo de informações de contato, dados pessoais e vínculos com modalidades.
* *Planos e Matrículas:* Controle de modalidades contratadas, tipos de planos e status das matrículas.
* *Agendamento de Aulas:* Mapeamento das aulas ofertadas, horários e alocação de instrutores responsáveis.
* *Gestão Financeira:* Registro e controle rigoroso do histórico de pagamentos e vencimentos.
* *Relatórios via SQL:* Consultas avançadas para análise de modalidades mais populares, faturamento e presença.


##  Modelagem do Banco de Dados

O banco de dados foi projetado seguindo as normas formais de modelagem relacional (DER) para garantir a integridade referencial das informações.

## Entidades Principais
* Alunos
* Professores
* Modalidades
* Planos
* Matriculas
* Aulas
* Pagamentos
